A "list" is one index-style page (root or a subcategory) and the CSV that feeds it. The root index and each subcategory page (e.g. F1, F-18) are each their own list.

List settings

Filenames are relative to where you'll actually save the files — the page fetches its CSV filename from its own folder at runtime.

Entries

Export the page HTML once, when first creating this list. After that, just re-export the CSV when entries change — the page reads it at runtime.

Attach to a list

On export, a matching entry is appended to that list's table on the Lists tab (you'll still need to export that list's CSV separately).
